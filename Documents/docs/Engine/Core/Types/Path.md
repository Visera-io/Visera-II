# Core.Types.Path (Visera.Core.Types.Path)

**Core.Types.Path** provides path type FPath, a cross-platform string for filesystem paths. With [Platform](../../Platform/index.md) Path implementation for platform format conversion (e.g. Windows backslash, volume); with [OS.FileSystem](../OS/FileSystem/index.md) for opening files. Path is string form; append, decompose or combine with CWD.
