# Runtime.Physics2D (Visera.Runtime.Physics)

**Runtime.Physics2D** provides 2D physics: common types (vector, AABB, collision shapes etc.) and rigid body dynamics. for collision detection/response, rigid body motion and constraints in 2D games; with [Graphics.Scene](../Graphics/Scene/index.md) to drive render entities from physics transform. module name in source may be Runtime.Physics or similar.

|------|------|
| [Common](Common.md) | 2D physics common types and constants.  |
| [RigidBody](RigidBody.md) | 2D rigid body and dynamics.  |
